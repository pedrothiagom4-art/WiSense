# WiSense

WiSense é uma plataforma experimental para pesquisa em Wi-Fi Sensing utilizando Python.

## Objetivos

- Simular sinais Wi-Fi
- Detectar movimento
- Gerar datasets
- Comparar algoritmos
- Futuramente utilizar captura real

## Tecnologias

- Python
- Matplotlib
- Streamlit
- Plotly
